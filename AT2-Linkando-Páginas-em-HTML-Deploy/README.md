# 🖥️ AT 2 Linkando Páginas em HTML - Deploy
> Esse diretório é um clone do diretório de mesmo nome. Esse diretório é dedicado ao aprendizado da realização de deploy no GitHub Pages
## 📝 Descrição do Projeto
Este projeto consiste em uma página desenvolvida em HTML básico e CSS para estilização.
Desenvolvido como parte da disciplina de **Desenvolvimento Front-End Para Web (2026.2)**, o sistema consiste em uma loja virtual moderna e temática focada no público gamer, contando com visual dark e destaques em roxo neon. A aplicação abrange páginas para Home (banner e benefícios), Produtos (vitrine de periféricos como teclados, mouses e headsets), Checkout (formulário de entrega e pagamento), Quem Somos (história e conceito da marca) e Contato (suporte ao cliente).

## 🚀 Tecnologias Utilizadas
- **Linguagem:** HTML5 e CSS3
- **Ferramentas:** VSCode
- **Modelo de IA:** Gemini

## 📊 Resultados e Aprendizados
O resultado foi um site estruturado e estilizado, implementando o link entre páginas.
- **Estruturação Semântica:** Aplicação prática de HTML5 para organização clara e acessível do conteúdo web.
- **Design Temático:** Construção de layout responsivo e estilização visual alinhada à estética gamer.
- **Interatividade e Formulários:** Criação de estrutura funcional para páginas de checkout e contato.
  
Foi aprendido também, a realização de deploy do repositório através do GitHub Pages

## 🧠 Declaração de Uso Ético da IA
Este projeto utilizou inteligência artificial (Gemini) estritamente como ferramenta de suporte tecnológico para o aprimoramento da estrutura semântica, organização do código e apoio com técnicas de estilização em CSS. Todo o código gerado foi revisado, testado e compreendido por mim, garantindo a minha responsabilidade integral sobre a autoria final, integridade e funcionamento da aplicação.
