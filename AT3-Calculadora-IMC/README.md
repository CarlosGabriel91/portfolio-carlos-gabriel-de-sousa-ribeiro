# 🖥️ AT 3 Calculadora IMC

## 📝 Descrição do Projeto
Este projeto consiste em uma aplicação web simples de arquivo único desenvolvida em HTML e JavaScript, sem estilização CSS externa ou frameworks. O propósito principal é entender a integração entre elementos de formulário HTML e a lógica funcional em JavaScript para o processamento de dados e interação com o usuário.
Desenvolvido como parte das disciplinas de **Desenvolvimento Front-End Para Web (2026.2)**, o sistema solicita os dados de peso (em kg) e altura (em metros) do usuário para calcular o Índice de Massa Corporal (IMC) e determinar a faixa de classificação correspondente (desde baixo peso até obesidade grau III).

## 🚀 Tecnologias Utilizadas
- **Linguagem:** HTML5 e JavaScript (Vanilla JS)
- **Ferramentas:** VSCode

## 📊 Resultados e Aprendizados
O resultado foi uma página simples, utilizando um pouco de JavaScript para realizar equações.

## 🧠 Declaração de Uso Ético da IA
Este projeto não utilizou nenhum modelo de inteligência artificial. Todo o código foi revisado, testado e compreendido por mim, garantindo a minha responsabilidade integral sobre a autoria final, integridade e funcionamento da aplicação.
