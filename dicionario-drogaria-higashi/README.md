# 🖥️ Dicionário Drogaria Higashi
## 📝 Descrição do Projeto
Este projeto consiste em uma página desenvolvida em HTML, CSS e JavaScript, com o propósito de aprendizagem e desenvolvimento de projeto acadêmico. O site é um dicionário de dados para um comércio real que necessitava de suporte na gestão de seu banco de dados. O Diagrama Entidade-Relacionamento, o documento de Especificação de Requisitos e as Regras de Negócio foram feitos em colaboração com colegas de turma. 
Desenvolvido como parte das disciplinas de **Modelagem de Banco de Dados (2026.2)**.

## 🚀 Tecnologias Utilizadas
* **Linguagem:** HTML5, CSS3, JavaScript
* **Modelo de IA:** Google AI Studio

## 📊 Resultados e Aprendizados
O resultado foi uma dicionário completo que armazena as informações de um banco de dados para um comércio real. 

## 🧠 Declaração de Uso Ético da IA
Este projeto utilizou inteligência artificial (Google AI Studio) diretamente em sua fundação, sendo responsável por gerar e organizar toda a estrutura de código, em todas as linguagens necessárias em seu desenvolvimento. O código gerado pelo modelo de IA foi revisado, testado e compreendido por mim, garantindo a minha responsabilidade integral sobre a autoria final, integridade e funcionamento da aplicação.
