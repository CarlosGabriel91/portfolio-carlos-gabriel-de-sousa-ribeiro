# 🖥️ AT 1 Páginas HTML
## 📝 Descrição do Projeto
Este projeto consiste em uma página desenvolvida em HTML básico, com o propósito de entender conceitos iniciais da linguagem 
e como aprimorar a estrutura de um código utilizando um modelo de inteligência artificial.
Desenvolvido como parte das disciplinas de **Desenvolvimento Front-End
Para Web (2026.2)**.

## 🚀 Tecnologias Utilizadas
* **Linguagem:** HTML5.
* **Modelo de IA:** Gemini

## 📊 Resultados e Aprendizados
O resultado foi uma página simples de apresentação e um formulário como teste. 
Aprendi estruturação básica de uma página em HTML e implementação de formulário simples.

## 🧠 Declaração de Uso Ético da IA
Este projeto utilizou inteligência artificial, modelo Gemini estritamente como ferramenta de suporte
tecnológico para estruturação semântica do HTML. Todo o código gerado foi revisado,
testado e compreendido por mim, garantindo a minha responsabilidade
integral sobre a autoria final, integridade e funcionamento da
aplicação.
